审计发现 · 按区域

每块最严重的问题

库存 · 供应商 · 商品 · POS

  • POS 整页没有 PageHeader，自己复制了一份页头和页签；44 个裸按钮，12 个裸输入框。
  • POS 深色模式下 text-white 叠在 bg-foreground 上不可见（3 处）。
  • 库存优先级用 stone / yellow / orange 三套色，供应商 PO 状态用 blue，废弃日志用 100 级填充色。
  • 4 份几乎相同的 KPI 卡片组件，10 种互不相同的空状态。

设置 · 报表 · 销售 · 通知等

  • settings 页 3,600 行里有 4 个手写 Switch、7 个手写可选项行、5 种 segmented 写法、4 种 eyebrow 拼法。
  • sales 图表 stroke="hsl(var(--border))" 写错格式（token 是 rgb），网格线一直没渲染出来。
  • subscribe 与 settings/billing 的 PlanRow 逐字节重复。
  • reports 22 个数字单元格全部缺 tabular-nums。

财务 · 客户 · 聊天 · 门店屏 · 打卡等

  • display 页 154 个 stone 类，且 darkMode ? … : … 三元和 dark: 变体同时生效，颜色互相打架。
  • chat 页 98 个 stone 类，FAB 带发光阴影，有一处两个分支完全相同的三元。
  • membership 页与 builder/[siteId]/membership 页是 785 行的双胞胎。
  • 131 处 font-mono 只有 1 处有 tabular-nums；punch-in 用了 6 个内联 svg 而非 Lucide。

共享组件 · 人事 · 培训

  • 276 个裸按钮（staffing-full 一个文件 63 个），8 个手写 Switch，9 份头像 initials 实现，4 套青/紫/玫红头像配色。
  • merchiva-quick-dialog 全部用内联 hex 样式：16px 圆角、四层发光阴影、无深色模式。
  • team/canvas 节点卡片用渐变和阴影；hub-nav 重新实现了一遍 PageHeader 和 PageTabs。
  • morning-briefing-card 用 rose / sky 两套非规范色调。

网站编辑器面板

  • 整个编辑器没有 import 过 Badge / Card / Table；116 个裸按钮，97 处任意圆角。
  • tool-bar 用 shadow-xl + 毛玻璃；html-editor 有 animate-ping；render-node 用蓝色徽标。
  • 三份重复的 PAGE_COLORS 数组（blue / rose / violet / cyan）。
  • flowfn 自带一套 40 个非 Lucide 图标和约 200 条注入式 CSS，还在全局 :root 上重新声明了 --stone-* 变量。

顺手发现的真 bug

  • suppliers 页 text-stone-800 没有 dark 变体，深色模式下文字不可读。
  • display 页的重复 dark: key 让后者覆盖前者。
  • globals.css 里 font-mono 映射到未加载的 JetBrains Mono，数字实际在用系统等宽字体（仍未修，见待办）。
  • 两处 React Compiler 报错顺手修掉：RestockCard 的 Date.now()、POS ProductCard 渲染期创建组件。

本轮没做的（按价值排序）

  • 修 globals.css 字体映射。在 @theme inline 加 --font-mono: var(--font-geist-mono)，删掉 Cascadia Code / JetBrains Mono 残留。一行改动，全站数字字体立刻正确。
  • merchiva-quick-dialog 重写。约 40 处内联 hex 样式换成 token 类，圆角 16px → rounded-lg，去掉四层发光阴影，顺便获得深色模式。
  • membership 双胞胎。把 app/manager/membership 与 app/manager/builder/[siteId]/membership 抽成一个 MembershipManager，只差 i18n 前缀。
  • 手写页头页签。POS 页、products/[productId]、personnel/hub-nav、builder/design 路由都该用 PageHeader + PageTabs；hub-nav 需要 PageTabs 支持前缀匹配和计数徽标。
  • flowfn。注入式 CSS 迁到 Tailwind + 原语，40 个自绘图标换 Lucide，删掉 :root 上的 --stone-* 声明。
  • 图表颜色。products、usage-section、team/canvas 里的 Recharts / SVG 仍用 hex，改用 var(--color-chart-N) 和 var(--border)。
  • sidebar / bottom-bar。本轮刻意没动，sidebar 里还有 7 处 rounded-[0.3rem]。
  • 原生控件。theme 页的 color / range input、html-properties-panel 的 click-to-deselect segmented 保持原样，换原语会改行为。
  • 旧 design.md。已被 design-system/README.md 取代，可以删除或改成指针。
