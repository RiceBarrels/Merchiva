The design system as it ships today

Read from the code, not from the old brief. Neutral gray tokens, 2.4px corners, 1px borders instead of shadows, Inter for interface text and a monospace face for every number. Where the older design.md disagrees with the code, the code is documented here and the gap is listed under Known drift.

Foundations

Principles

Tools, not demos

Built for the fifth-time user. Dense, predictable, no hero sections inside /manager/.

Borders over shadows

Structure is a 1px border-border. Shadows appear only on popovers.

Monospace for data

Prices, SKUs, IDs, timestamps: font-mono tabular-nums.

Semantic tokens first

text-foreground, bg-muted. Direct stone-* classes are legacy.

Density over whitespace

Spacing unit is 0.24rem, 4% tighter than stock Tailwind.

Motion with purpose

200–300ms transitions, spring taps on mobile, haptics on every button.

Notes

Known drift between docs and code

  1. Radius is 0.15rem, not 0.3rem. Changed in commit 3344896 (2026-05-17). design.md, the showcase page and some rounded-[0.3rem] pickers still assume 0.3rem. --radius-sm now clamps to 0.
  2. Tokens are rgb(), not oklch(), and the chart ramp is blue, not gray.
  3. Font declarations conflict. globals.css :root declares Cascadia Code and JetBrains Mono while layout.tsx puts Inter and Geist Mono on the same element. font-mono maps to --font-mono (JetBrains Mono, not loaded), so data falls back to the system monospace. Fix: --font-mono: var(--font-geist-mono) in @theme inline, delete the leftovers.
  4. font-heading on CardTitle is undefined and silently inherits Inter.
  5. Dark sidebar-primary is blue rgb(20 71 230); unused by the sidebar today.
  6. --spacing: 0.24rem shrinks every spacing utility by 4%. Do not mix in hardcoded px that assume a 4px grid.
  7. design.md still says BizOps, Supabase and Clerk. The README in this folder supersedes it.
